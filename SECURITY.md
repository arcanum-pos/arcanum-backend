# Security policy

Thank you for helping keep Arcanum and the organisations that use it safe.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately instead:

- on GitHub: this repository's **Security** tab → **Report a vulnerability**;
- this applies to every part of Arcanum, including the sign-in service
  login.kaboutersoft.be and arcanum.kaboutersoft.be - report those here too.

Describe what you found, how to reproduce it, and what an attacker could do
with it. We'll confirm receipt, keep you informed, and credit you in the
advisory if you wish.

Please give us reasonable time to release a fix before disclosing anything,
and don't access or change data that isn't yours while testing - try it on
your own installation or the demo.

## Supported versions

Only the latest release is supported. Installations update through their
installer; see the release notes at https://arcanum.kaboutersoft.be/releases.
